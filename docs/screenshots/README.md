# Screenshots Directory

Esta carpeta contiene screenshots profesionales del proyecto para uso en portfolio de Fiverr.

## 📸 Screenshots Disponibles

**Pendiente de captura**. Ver [`../SCREENSHOTS.md`](../SCREENSHOTS.md) para guía detallada de qué capturar.

### Estructura recomendada:
```
screenshots/
├── admin-analytics-full.png
├── admin-analytics-metrics.png
├── admin-feedback-full.png
├── admin-beta-testers.png
├── public-webapp-detail.png
├── public-faq-guarani.png
└── widget-feedback.png
```

## 🎯 Uso

1. Captura screenshots siguiendo la guía en `SCREENSHOTS.md`
2. Guárdalos en esta carpeta con nombres descriptivos
3. Optimiza tamaño sin perder calidad
4. Úsalos en:
   - Fiverr Gig Gallery
   - Fiverr Portfolio
   - README.md principal
   - PORTFOLIO.md

---

**Nota:** Archivos de imágenes grandes (>1MB) pueden agregarse al `.gitignore` si deseas mantener el repo ligero.
