## 📐 Especificaciones Técnicas

### Resolución & Formato
- **Resolución mínima:** 1920x1080 (Full HD)
- **Formato:** PNG (mejor calidad) o JPG (menor tamaño)
- **Aspect ratio:** 16:9 preferido

### Herramientas Recomendadas
- **Windows:** Snipping Tool, ShareX, Greenshot
- **Mac:** Screenshot nativo (Cmd+Shift+4), CleanShot X
- **Linux:** Flameshot, GNOME Screenshot
- **Browser Extension:** Awesome Screenshot, Full Page Screen Capture

### Tips de Captura
1. **Limpia el navegador**: Oculta bookmarks bar, extensiones visibles
2. **Zoom 100%**: Para proporciones reales
3. **Sin cursor**: Más profesional
4. **Datos reales**: Usa datos de ejemplo variados, no texto "lorem ipsum"
5. **Scroll completo**: Para dashboards largos, usa herramientas de full-page screenshot
